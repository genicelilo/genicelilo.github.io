Kebijakan Privasi

Berlaku sejak 27 Oktober 2026

Aplikasi "Genice YouTube" adalah alat pribadi yang hanya dipakai oleh pemilik channel YouTube Genice & Lilo untuk mengunggah video ke channel miliknya sendiri.

Data yang digunakan

  • Aplikasi meminta izin Google youtube.upload hanya untuk mengunggah video ke channel pemilik.
  • Token izin disimpan di komputer pribadi pemilik, tidak dikirim ke server lain.
  • Aplikasi tidak mengumpulkan, menjual, atau membagikan data pribadi siapa pun, termasuk data penonton.

Konten anak

Channel Genice & Lilo ditandai sebagai "dibuat untuk anak" sesuai aturan YouTube. Kami tidak mengumpulkan data dari penonton anak.

Mencabut izin

Izin dapat dicabut kapan saja di myaccount.google.com/permissions.

Penggunaan data dari Google API mengikuti Google API Services User Data Policy.
